## 12. Data Collection, Privacy, and User Rights Notice

BubblesTheDev is committed to protecting user privacy.

The BubblesTheDev Web Browser is designed around local-first handling of browser data, user control, transparency, accessibility-focused improvements, and privacy-focused defaults.

The BubblesTheDev Web Browser does not include built-in telemetry, built-in analytics services for ordinary browsing, built-in behavioral advertising profiles, or built-in cloud synchronization by default.

Specifically:

* No telemetry services are embedded in the Software.
* No background analytics services are executed.
* No behavioral tracking mechanisms are included.
* No advertising identifiers are generated or transmitted.
* No cloud-based synchronization features are implemented.
* Automatic diagnostics upload is not enabled by default for ordinary diagnostics behavior.
* No built-in silent auto-updater service is included.

Ordinary browser data is intended to remain on the user's device unless the user chooses to interact with websites, search providers, downloads, supported streaming services, update flows, privacy-safe diagnostics features where supported, optional anonymous feedback, or other third-party services through normal browser use.

Local browser data may include, where applicable, settings, history, bookmarks, saved-password metadata, encrypted password storage, browser profile preferences, per-site permission settings, toolbar visibility, bookmark bar visibility, shell theme preferences, supported streaming-session data, optional Music Player and Music Downloader settings, local AI settings and profile-isolated AI memory where supported, cached internal search suggestions, install-linked metadata, language preferences, accessibility preferences, Developer Workspace preferences, local website app records, local PDF metadata, toolbar clock preferences, local sidebar preferences, and browser-feature preferences.

The Software may write browser-state data locally and may protect that data with compressed persistence, operating-system-backed protection, credential-backed protection, or other local protection mechanisms where available.

Saved passwords are stored separately from the main browser data file and are intended to be encrypted before being written to disk.

Diagnostics are generated locally. Runtime diagnostic entries may be written to a local diagnostics directory. Privacy-safe diagnostics are intended to remain user-controlled, narrower than general browser data collection, and disabled by default unless the user enables them where supported.

Optional local AI features, if included, are intended to support on-device behavior where available. Standard profiles may keep encrypted AI memory locally, while incognito or other ephemeral contexts are intended to avoid persistent AI memory.

Optional anonymous feedback, if used, is intended for short product feedback. It does not request a name, email address, account handle, or reply-to field. It does not attach browser activity, profile data, local files, diagnostics exports, crash reports, linked identity state, or AI memory.

Virtual Machine Center, if included, is a browser-owned guide for VMware Workstation Pro and Linux ISO setup. It is not designed to install VMware, create virtual machines, automate VMware, run Linux commands, read VM files, read VM memory, or upload ISO contents or hashes.

The browser may include accessibility-focused features intended to improve reading comfort, visibility, motion reduction, control size, and continuity across sessions. Accessibility preferences are intended to remain local to the user's device by default.

The browser may include background update checks and background installer downloads where supported, while keeping a browser-controlled installer-based update model. Where supported, installed builds may show update download and install progress, perform an extra local save and session-flush pass before update installation closes the browser, and then hand off to the regular installer so the user can complete the installer prompts. That update model is intended to remain visible and user-controlled rather than a hidden silent updater service.

The browser may still generate normal network traffic when the user opens websites, signs into services, downloads files, uses search features, uses passkeys or WebAuthn, uses update checks, manually sends approved diagnostics or anonymous feedback, or uses supported online features. Third-party websites and services may process information under their own privacy policies, cookie policies, and terms.

The browser is not designed to make legal, financial, employment, health, housing, insurance, government-benefit, or similarly significant automated decisions about users.

Users may have privacy, transparency, access, correction, deletion, portability, restriction, objection, accessibility, or related legal rights depending on their location and applicable law.

Any future feature that would materially change this privacy posture would be disclosed in updated license, privacy, or release documentation.
