Before You Run It

On some Windows systems, you may see a standard SmartScreen or antivirus prompt before the installer opens.

If Windows SmartScreen or your antivirus shows a warning, review the installer name, version, and source before continuing.

  • Download only from the official website or the official GitHub release page
  • Verify the installer name and version match the page
  • Review the public privacy and documentation pages if you want more detail first
  • Continue only if the file matches the official release you intended to download.
